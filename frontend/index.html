      Formula reference

      Use a for the raster selected in that statistic. Presets are editable.

      Functions

      • sum(a) — Add pixel values. To add only values above 10, use sum(a, where=a > 10).
      • areaha(a == 4) — Ground area in hectares where the value is 4. For values above a threshold, use areaha(a > 10). Includes the fraction of each matching pixel inside your box or selected polygons.
      • count(a) — Number of valid pixels. Use count(a > 10) to count matching pixels.
      • mean(a) — Average pixel value. For a selected group, use mean(a, where=a > 10).
      • min(a) — Smallest pixel value.
      • max(a) — Largest pixel value.

      sum, count, mean, min, and max accept an optional where=condition. areaha takes one condition.

      Operators and combinations

      • Arithmetic: + - * /. Example range: max(a) - min(a).
      • Comparisons: < <= > >= == !=. Example class: a == 4.
      • Conditions: && (and), || (or), ! (not). Example: areaha(a > 10 && a <= 20).
      • Percentage of valid pixels: 100 * count(a > 10) / count(a).
      • Percentage of valid ground area: 100 * areaha(a > 10) / areaha(a == a).

      sum(a > 10) counts matches; sum(a, where=a > 10) adds their values. Functions cannot be nested inside other functions.

      NoData is excluded. Numeric functions select pixels by their centers. areaha measures their fractional intersection on the WGS 84 ellipsoid, including polygon holes and counting overlaps once. It requires a WGS84 geographic or projected raster; complex geometry may need a smaller area.

      Calculations use native pixels and stored values. Each areaha term is in hectares; arithmetic can change the final units. Multiple-raster expressions are coming separately.

      Performance tuning (experimental)

      Shared by these statistics. Changes how many native pixels are processed together, not their resolution. Larger batches need more memory. Choose a size, then Calculate to compare timings.
