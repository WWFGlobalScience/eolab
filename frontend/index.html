    Formula reference
              
    Area formulas use the same box, imported polygons or filtered vector layer as Summary statistics. Each formula uses a for each selected raster in turn, on its own pixel grid.
    
              
      
                
    • pixelValue(a) — Native pixel at your last map click, independent of the selected area.
      • 
                
    • mean(a) — Average of valid pixel values.
      • 
                
    • stdev(a) — Population standard deviation of valid selected pixels. One pixel gives zero; no matching pixels gives no value.
      • 
                
    • min(a) / max(a) — Smallest / largest valid value.
      • 
                
    • sum(a) — Sum of valid pixel values.
      • 
                
    • count(a > 10) — Count matching pixels.
      • 
                
    • areaha(a > 0) — Matching ground area in hectares.
      • 
              
    
              
    Use arithmetic to combine functions: (mean(a)-min(a))/(max(a)-min(a)). Use where= to filter area statistics: sum(a, where=a > 10). No-data pixels are excluded. Up to five formulas share one calculation per raster. Assign statistics with different units or ranges to separate plots as needed.

    Help
              
    Local layers are saved on this device. Shared layers show everyone’s polygons; you can edit only your own. Share copies the joining code. Removing a layer from your map does not delete its shared polygons. Export GeoJSON to keep a file. Map links include live shared layers, but not private polygons or editing credentials.
    
              
    GeoJSON imports polygon names and notes. EOLab exports also preserve contributor names and colors; other attributes and styles are ignored. Imported polygons become yours when you share them in a new layer.
